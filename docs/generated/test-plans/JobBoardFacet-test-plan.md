# Тест-план: JobBoardFacet — Доска заказов

> Сеть: Base Sepolia · Diamond: `0xF00CC71878c226E0b64253Fb71dD802aF12165D0` · USDC: `0x036CbD53842c5426634e7929541eC2318f3dCF7e`
> Тестер: — · Дата: —

Тестируем создание/отклик/приём/отмену заказов через UI. Нужны два кошелька — Клиент с USDC и Исполнитель.

---

## Сценарий 1: Клиент создаёт заказ

**Роль:** Клиент
**Страница:** `/board` → вкладка «Jobs» → кнопка «Post Job» (или `/board/client/post`)
**Предусловие:** кошелёк Клиента подключён, есть тестовый USDC

- [ ] Открыть страницу создания заказа
- [ ] Заполнить поле **Title** (например: «Smart contract audit»)
- [ ] Заполнить поле **Description** (полное описание задания)
- [ ] Указать **Amount** (бюджет в USDC, например: 100)
- [ ] Указать **Deadline** (количество дней)
- [ ] Выбрать **Region** из выпадающего списка
- [ ] Нажать **«Post Job»** → MetaMask просит подписать permit, потом транзакцию
- [ ] Подтвердить обе подписи → тост «Job posted!», редирект на `/job/[id]`

**Проверить после:**
- [ ] Заказ появился на доске `/board` в списке открытых заказов
- [ ] На странице `/job/[id]` отображаются все введённые данные (название, бюджет, дедлайн, регион)
- [ ] Статус заказа «Open»
- [ ] USDC списан с кошелька Клиента (сумма + комиссия платформы)

## Сценарий 2: Исполнитель откликается на заказ

**Роль:** Исполнитель
**Страница:** `/job/[id]`
**Предусловие:** заказ в статусе «Open», кошелёк Исполнителя подключён

- [ ] Открыть страницу заказа `/job/[id]`
- [ ] Видна секция **«Apply to take this job»** с кнопкой **«Apply»**
- [ ] Нажать **«Apply»** → подтвердить gasless-транзакцию в кошельке
- [ ] Тост «Application sent» → плашка статуса сменилась на «Application sent · Waiting for client»

**Проверить:**
- [ ] Переключиться на Клиента — в секции «Applicants» появился адрес Исполнителя
- [ ] Кнопка «Apply» у Исполнителя исчезла (повторный отклик заблокирован)
- [ ] Клиент может кликнуть на адрес Исполнителя в списке — ведёт на профиль

---

## Сценарий 3: Клиент нанимает исполнителя

**Роль:** Клиент
**Страница:** `/job/[id]`
**Предусловие:** есть хотя бы один откликнувшийся исполнитель

- [ ] Переключиться на кошелёк Клиента, открыть `/job/[id]`
- [ ] В секции «Applicants» найти нужного исполнителя
- [ ] Нажать **«Hire»** рядом с его адресом → появляется модальное окно подтверждения
- [ ] Проверить данные в модалке: Executor, Budget, Deadline, Region/Fee
- [ ] Прочитать предупреждение (средства будут заблокированы до завершения сделки)
- [ ] Нажать **«Confirm Hire»** → gasless-транзакция → тост «Executor accepted!»
- [ ] Автоматический редирект на `/deal/[адрес-сделки]`

**Проверить после:**
- [ ] Статус заказа сменился на «Accepted»
- [ ] Другие исполнители больше не могут откликнуться или быть нанятыми
- [ ] Исполнитель видит плашку «You were hired · Agreement created» с кнопкой «Go to Deal»
- [ ] Остальные откликнувшиеся видят «Position filled · You were not selected»

## Сценарий 4: Клиент отменяет заказ

**Роль:** Клиент
**Страница:** `/job/[id]`
**Предусловие:** заказ в статусе «Open» (никто ещё не нанят), Клиент передумал

- [ ] Открыть `/job/[id]` под кошельком Клиента
- [ ] Нажать кнопку **«Cancel Job»** (обычно в нижней части или рядом с деталями)
- [ ] Подтвердить транзакцию → тост «Job cancelled. Budget refunded.»
- [ ] Редирект на доску или статус меняется на «Cancelled»

**Проверить:**
- [ ] USDC (бюджет, без комиссии платформы) вернулся на кошелёк Клиента
- [ ] Кнопка «Apply» у исполнителей исчезла
- [ ] Заказ не отображается в списке открытых на `/board`

---

## Граничные случаи

- [ ] **Пустой title:** попробовать создать заказ без названия → кнопка «Post Job» заблокирована или revert
- [ ] **Нулевой бюджет:** ввести 0 USDC → ошибка валидации
- [ ] **Исполнитель пытается нанять сам себя:** откликнуться и потом нажать «Hire» на свой адрес → revert (SelfApply защита)
- [ ] **Двойной отклик:** нажать «Apply» второй раз → кнопка недоступна, транзакция reverts с AlreadyApplied
- [ ] **Чужой отменяет заказ:** подключить кошелёк не-клиента и нажать «Cancel Job» → revert
- [ ] **Hire после нашего отклика другим:** клиент уже нанял кого-то → кнопка «Hire» у остальных исчезла
- [ ] **Очень длинное description:** 10 000+ символов → должно быть ограничение
