# Тест-план: OfferNFTFacet — NFT-офферы исполнителей

> Сеть: Base Sepolia · Diamond: `0xF00CC71878c226E0b64253Fb71dD802aF12165D0` · USDC: `0x036CbD53842c5426634e7929541eC2318f3dCF7e`
> Тестер: — · Дата: —

OfferNFT — ERC-1155 NFT который исполнитель минтит как «визитку» с ограниченным тиражом. Клиенты покупают NFT чтобы нанять этого исполнителя или иметь приоритет. Тестируем через UI Service Board / Executor Board.

---

## Сценарий 1: Исполнитель создаёт оффер-NFT

**Роль:** Исполнитель
**Страница:** `/board/executor` → «Create Offer NFT» или `/board/executor/post`
**Предусловие:** кошелёк Исполнителя подключён

- [ ] Открыть форму создания оффера
- [ ] Заполнить **Title** — название оффера
- [ ] Заполнить **Description** — что включает оффер
- [ ] Указать **Price** — цена одного NFT в USDC
- [ ] Указать **Supply** — максимальное количество (например: 10)
- [ ] Нажать **«Create Offer»** → MetaMask → подтвердить
- [ ] Тост «Offer created!», оффер появился на доске

**Проверить:**
- [ ] На `/board/executor` видна карточка с ценой и оставшимся supply
- [ ] Через basescan: токен задеплоен, `totalSupply(tokenId) = 0` (ещё не куплен никем)

---

## Сценарий 2: Клиент покупает оффер-NFT

**Роль:** Клиент
**Страница:** `/board/executor` → карточка оффера → «Buy Offer»
**Предусловие:** оффер создан, у Клиента есть USDC

- [ ] Найти оффер на доске, открыть карточку
- [ ] Нажать **«Buy»** / **«Get Offer»** → MetaMask: permit на USDC + транзакция
- [ ] Подтвердить → тост «Offer purchased!»

**Проверить после:**
- [ ] Баланс USDC у Клиента уменьшился на цену оффера
- [ ] Исполнитель получил USDC (минус платформенная комиссия)
- [ ] ERC-1155 токен появился в кошельке Клиента (видно на basescan)
- [ ] Supply оффера уменьшился на 1 (если был 10 — стал 9)

---

## Сценарий 3: Supply исчерпан — больше купить нельзя

**Предусловие:** оффер с supply = 1, его уже кто-то купил

- [ ] Открыть карточку оффера
- [ ] Кнопка «Buy» недоступна / показывает «Sold Out»
- [ ] Если нажать через скрипт → revert (SupplyExhausted или аналог)

---

## Сценарий 4: Исполнитель просматривает свои продажи

**Страница:** `/dashboard` или профиль исполнителя
**Предусловие:** хотя бы один оффер куплен

- [ ] Открыть дашборд под кошельком Исполнителя
- [ ] Видна статистика офферов: сколько куплено, объём USDC

---

## Граничные случаи

- [ ] **Цена = 0** → ошибка валидации или revert (ZeroPrice)
- [ ] **Supply = 0** → ошибка или revert (ZeroSupply)
- [ ] **Покупка своего оффера** → revert (SelfPurchase / аналог)
- [ ] **Оффер в несуществующем tokenId** → `balanceOf(addr, id)` = 0, не revert
- [ ] **Смена SVG-рендерера (setSvgRenderer)** — только owner Diamond. Попытка от чужого → revert
- [ ] **Передача ERC-1155 токена третьему лицу** — в отличие от JobReceipt, OfferNFT **переводим**, это нормально
