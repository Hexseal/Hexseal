# Frontend: Admin Panel
> **Файл:** `frontend/src/app/admin/page.tsx`

Панель администратора (только Diamond owner). Управление протоколом.

## User Flows
- Arbiter Registry: добавление/удаление арбитров
- Chief Arbiter: назначение и отзыв
- Arbiter Archive: поиск по истории решений
- Dispute Lookup: ручной поиск по адресу сделки
- Protocol settings: threshold, fees, pause

## Known Edge Cases
- Кошелёк не подключён → показывается prompt подключения
- Неправильная сеть (не Base Sepolia) → показывается предупреждение
- USDC баланс = 0 → кнопки с USDC заблокированы, показывается сумма
- VPN → цена определена как $10, лейбл "VPN · $10"
