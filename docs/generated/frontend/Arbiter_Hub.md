# Frontend: Arbiter Hub
> **Файл:** `frontend/src/app/arbiter/page.tsx`

Интерфейс арбитра: список споров, клейм, разрешение, история.

## User Flows
- Open Disputes: просмотр некленутых споров
- Commit → Claim (двухшаговый commit-reveal)
- My Cases: активные дела арбитра
- Resolve: clientWins / executorWins через relay
- History: поиск по адресам (deal / client / executor)
- Manage (chief): добавление/удаление арбитров

## Known Edge Cases
- Кошелёк не подключён → показывается prompt подключения
- Неправильная сеть (не Base Sepolia) → показывается предупреждение
- USDC баланс = 0 → кнопки с USDC заблокированы, показывается сумма
- VPN → цена определена как $10, лейбл "VPN · $10"
